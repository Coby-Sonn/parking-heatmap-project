# 🅿️ מפת חום לזמינות חניה - Parking Heatmap

מערכת מתקדמת להצגת נתוני זמינות חניה בפורמט מפת חום אינטראקטיבית.

## 🏗️ ארכיטקטורה חדשה

### 📋 סקירת המערכת
המערכת עוברת לארכיטקטורה חדשה מבוססת בחירת חניון, המיועדת להתמודד עם נפחי נתונים גדולים (120k+ רשומות) בצורה יעילה.

### 🔄 זרימת המשתמש
```
1. דף הבחירה (index.html) → רשימת כל החניונים
2. חיפוש וסינון חניונים
3. בחירת חניון ספציפי
4. מעבר לדף מפת החום (heatmap.html)
5. טעינת נתונים עם פגינציה
6. הצגת מפת חום שבועית
```

## 🚀 תכונות עיקריות

### ✅ דף בחירת חניון (index.html)
- **טעינה מהירה**: נתוני חניונים נטענים מקובץ JSON מקומי
- **חיפוש מתקדם**: חיפוש לפי שם, קוד או ID
- **ממשק נעים**: קלפי חניון אינטראקטיביים עם אייקונים

- **מפת חום אינטראקטיבית**: הצגת נתונים לשבוע מלא
- **תיקון זמנים**: המרת זמן נכונה עם התחשבות בשעון קיץ/חורף
- **סטטיסטיקות**: מידע מפורט על כמות הנתונים

## 🔧 פתרונות טכניים

### 🗃️ פתרון בעיית הנתונים
**הבעיה**: רק 1000 רשומות נטענו מתוך 10k+ ברשומות  
**הפתרון**: מימוש פגינציה אוטומטית ב-`DataFetcher`

```javascript
// טעינת כל הנתונים עם פגינציה
async fetchLotData(lotName, daysBack = 7) {
  let allData = [];
  let offset = 0;
  
  while (hasMore) {
    const batch = await supabase
      .range(offset, offset + 1000 - 1)
      .eq('lot_name', lotName);
    
    allData.push(...batch);
    offset += 1000;
  }
  
  return allData;
}
```

### 🕐 תיקון המרת זמן
**הבעיה**: נתוני יום ראשון הוצגו כיום שבת  
**הפתרון**: המרת זמן נכונה עם UTC+2 קבוע

```javascript
function getLocalDayHourMinute(utcString) {
  const d = new Date(utcString);
  const israelOffset = -120; // UTC+2
  const localTime = new Date(d.getTime() - (israelOffset * 60 * 1000));
  
  return {
    day: localTime.getDay(),
    hour: localTime.getHours(),
    minute: localTime.getMinutes()
  };
}
```
